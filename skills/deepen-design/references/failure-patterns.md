# Failure Patterns After “Still Generic”

Read this when a user rejects a visually polished result.

## Leaf-first refinement

Symptoms:

- many changes to shadows, borders, gradients, type tracking, and hover states;
- almost no change to page structure, proof, assets, or interaction;
- final report lists craft categories instead of a new design argument.

Response: return to D0-D2. Do not add another polish pass.

## Anti-slop convergence

Symptoms:

- no purple glow, no equal feature cards, no obvious accessibility mistake;
- yet every page becomes warm neutral, one muted accent, oversized grotesk,
  mono metadata, large whitespace, rounded product panels, and subtle motion.

Cause: negative rules remove common failures but cannot generate an ownable
positive direction.

Response: define two product-derived metaphors and signature mechanics before
running the anti-slop linter.

## Score substitution

Symptoms:

- Lighthouse, tests, responsive checks, or a self-authored 98/100 rubric are
  used to answer a taste complaint;
- “brand specificity” receives full marks without reference comparison,
  logo-off testing, recall testing, or user confirmation.

Response: keep functional gates, discard the absolute taste score, and run
pairwise visual evaluation.

## Single-path lock-in

Symptoms:

- the first inferred design read becomes the implementation;
- references are consulted only after the direction is chosen;
- every later iteration optimizes the same local maximum.

Response: generate two real alternatives at D1, D2, and D3. Keep a challenger
until a rendered comparison resolves the fork.

## Screenshot theater

Symptoms:

- screenshots prove absence of overflow and console errors;
- no screenshots are compared side by side;
- full-page capture hides weak section rhythm or unrevealed content;
- the evaluator narrates “refined” without naming a visible delta.

Response: capture fixed viewports at identical scroll positions, hide logos,
and compare before/A/B on one criterion at a time.

## Generic content in expensive clothing

Symptoms:

- generic stock photography;
- interchangeable SaaS promises;
- screenshots that show UI but not the product’s special causal mechanism;
- a repeated “headline + body + visual” rhythm.

Response: expose real evidence, decisions, state transitions, and domain
artifacts. Let product behavior create the visual language.
